# 🐾 Fantastic Animals

A project developed during the **Complete JavaScript ES6 Course** by [Origamid](https://www.origamid.com/), focused on mastering modern JavaScript through hands-on, real-world applications.

## 🚀 About the Project

**Fantastic Animals** is a simple yet dynamic website built to practice the main functionalities of JavaScript.  
The layout was created using **CSS Grid**, with the primary focus on implementing **interactive features** and improving JavaScript logic.

## 🧠 What I Learned

Throughout the course and project development, I worked on several modern JavaScript concepts and web interaction techniques, including:

- 🧩 **DOM manipulation**  
- 🌐 **Fetch API** for data requests  
- ⚡ **Arrow functions**, **Promises**, and **async/await**  
- 🔁 **setInterval** and time-based functionality  
- ⚙️ **Debounce** for event optimization  
- 🪄 **Tabs**, **accordions**, and **tooltips**  
- 📱 Responsive **dropdown** and **mobile menus**  
- 🎞️ **Smooth scrolling** with animations  
- 📊 Fetching data from **local JSON** and **external APIs**  

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Grid Layout)  
- JavaScript ES6+
